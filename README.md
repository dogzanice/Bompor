**สถานที่:** ณ ร้านโกโก้ตาหลวง (อ.ทุ่งสง) & บริษัท รักษ์จันทน์110 จำกัด (อ.ร่อนพิบูลย์)

## 🌟 จุดเด่นของระบบ
1. **ฟรี 100% ไม่เสียค่าใช้จ่าย**: ทำงานแบบ Client-Side บนเบราว์เซอร์ 100% ไม่ต้องเช่า Server หรือฐานข้อมูล
2. **ใช้งานสะดวกบนมือถือ (Mobile-First)**: ปุ่มใหญ่ ตัวหนังสืออ่านง่าย รองรับการถ่ายรูปสดจากกล้อง หรือเลือกภาพจากคลังภาพ
3. **ระบบบีบอัดรูปภาพอัตโนมัติ (Client-Side Compression)**: ลดขนาดไฟล์ภาพถ่าย 5–15 MB จากกล้องมือถือ ให้เหลือ ~200–300 KB ทันที ไม่เปลืองเน็ตและ Export รวดเร็ว
4. **1-Click Export Word (.docx)**: กดดาวน์โหลด จะได้ไฟล์ Microsoft Word (`.docx`) ที่จัดหน้าและฟอนต์ (TH SarabunPSK) ตรงตามแม่แบบเอกสารราชการเดิม 100% พร้อมฝังรูปภาพลงในกรอบเรียบร้อย
5. **Auto-Save Draft**: บันทึกข้อมูลและรูปภาพลงเครื่องอัตโนมัติ หากเผลอปิดหน้าจอหรือเน็ตหลุด ข้อมูลไม่สูญหาย
6. **ตัวอย่างแนวทางคำตอบ (Quick Sample Prompts)**: มีปุ่มช่วยใส่ตัวอย่างคำตอบสำหรับนักศึกษาที่คิดข้อความไม่ออก สามารถกดใส่แล้วปรับแก้เป็นของตัวเองได้ทันที
7. **พิมพ์ / บันทึก PDF (A4 Ready)**: รองรับการสั่งพิมพ์รายงาน A4 หรือบันทึกเป็นไฟล์ PDF ได้ทันที

## 🚀 วิธีการเปิดใช้งาน

### วิธีที่ 1: เปิดใช้งานในเครื่องทันที (Offline / Local)
- ดับเบิลคลิกไฟล์ **`index.html`** เพื่อเปิดใน Google Chrome, Safari, หรือ Edge ได้ทันที

### วิธีที่ 2: นำไปเปิดเป็นเว็บแอปให้นักศึกษาทุกคนใช้งานผ่านมือถือ (แนะนำ & ฟรี 100%)

#### 📌 ตัวเลือก A: โฮสต์ฟรีด้วย GitHub Pages (ง่ายและถาวร)
1. อัพโหลดโฟลเดอร์นี้ขึ้น GitHub Repository
2. ไปที่ **Settings** > **Pages**
3. เลือก Branch เป็น **main** (Root) แล้วกด **Save**
4. จะได้ลิงก์ เช่น `https://username.github.io/study-trip-report/` ส่งให้นักศึกษาเปิดใน LINE หรือ Safari ได้ทันที

#### 📌 ตัวเลือก B: โฮสต์ฟรีด้วย Vercel / Netlify / Cloudflare Pages
1. ลากโฟลเดอร์นี้ไปวางที่ [Vercel.com](https://vercel.com) หรือ [Netlify.com](https://netlify.com)
2. ได้รับลิงก์ URL เว็บแอปทันที นำไปแจกจ่ายให้นักเรียนใช้งานได้เลย

## 📁 โครงสร้างไฟล์ในโครงการ

| ชื่อไฟล์ | คำอธิบาย |
|---|---|
| `index.html` | หน้าเว็บแอปหลัก (ฟอร์มบันทึก, แถบสถานะ, ตัวอย่างเอกสาร A4 Live Preview) |
| `app.js` | ระบบควบคุมฟอร์ม, บันทึกร่างอัตโนมัติ, ย่อขนาดรูปภาพ และคัดลอกสรุป |
| `docx-generator.js` | Engine ประมวลผลและสร้างไฟล์ Word (.docx) ในเครื่องแบบเรียลไทม์ |
| `template-base64.js` | แม่แบบเอกสาร Word ต้นฉบับ (พร้อมตราสัญลักษณ์และโครงสร้างตาราง) |
| `jszip.min.js` | ไลบรารีสำหรับจัดการไฟล์ Zip/OpenXML ในเครื่องแบบ Offline |
| `แบบบันทึกนักเรียน นักศึกษา.docx` | ไฟล์เอกสารต้นฉบับ |
